04
Recovery · 恢复

断线重连只剩一个变量：游标

拖滑块选一个游标，再点「重连」。服务端只认 epoch 与 sequence，不认时间。水位以下的游标一律拒绝，而不是悄悄返回残缺后缀。

05
State on disk · 落盘

一个目录装下全部状态

默认 ~/.pi-adaptor。目录 0700，文件 0600。每个 JSON 都走「临时文件 → fsync → rename → 目录 fsync」。

06
Tradeoffs · 取舍

每一条捷径都标了价

这些不是风格偏好，是读过失败路径之后的选择。右列写的是代价，不是好处。

取舍选择代价
会话存储复用原生 Pi v3 JSONL，不另建会话库必须校验外部写入：比对 inode 与旧字节前缀，不符即转只读
并发单进程 + 每会话一把 KeyedMutex只能单机部署，多副本要靠外部路由
事件追加日志 + 内存水位，过期游标报 CURSOR_EXPIRED客户端必须实现全量 resync
幂等服务端持久化写结果，24 小时重放窗口结果必须 JSON 可序列化；含令牌的方法被排除
媒体sha256 内容寻址 + 扫历史引用做 GCGC 前读遍所有会话，任一读取失败就放弃整轮
Skill内容哈希做版本目录，rename 原子发布同名不同内容会累积多个版本目录
版本唯一来源 package.json，构建脚本拒绝漂移发布要同时改 package.json、host-release.json、tag
